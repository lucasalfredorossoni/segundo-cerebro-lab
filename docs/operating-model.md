# Modelo Operacional

## Principios

- Comecar pequeno e verificavel.
- Separar experimento de rotina.
- Versionar conhecimento, nao segredo.
- Manter contratos de integracao legiveis.
- Preferir automacoes simples antes de plataformas complexas.

## Fluxo de trabalho

1. Capturar uma necessidade concreta.
2. Registrar no roadmap com resultado esperado.
3. Prototipar em `experiments/`.
4. Promover o que funcionou para a area correta.
5. Documentar como executar, testar e manter.

## Definicao de pronto

Uma entrega esta pronta quando:

- tem dono e finalidade claros;
- pode ser executada por outra pessoa seguindo a documentacao;
- nao depende de credenciais versionadas;
- deixa evidente onde ficam entradas, saidas e logs;
- tem proximo passo ou criterio de encerramento.

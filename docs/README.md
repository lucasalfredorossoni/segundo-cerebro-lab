# Docs

Documentacao viva do laboratorio.

Use esta pasta para registrar processos, decisoes, padroes operacionais e o
roadmap. A regra e simples: se algo sera repetido ou explicado para outra pessoa
no futuro, documente aqui.

## Indice

- `roadmap.md`: fila de prioridades e proximos ciclos.
- `operating-model.md`: como o laboratorio deve funcionar no dia a dia.
- `data-policy.md`: limites para dados, privacidade e versionamento.
- `stack.md`: escolhas tecnicas iniciais.
- `decisions/`: decisoes arquiteturais e operacionais.

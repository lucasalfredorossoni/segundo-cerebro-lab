# 0001 - Estrutura inicial do laboratorio

## Contexto

O repositorio nasceu como um laboratorio operacional para dados, automacoes,
estudos, conteudo e integracoes.

## Decisao

Separar o trabalho em seis areas:

- `docs/` para documentacao e decisoes.
- `automations/` para rotinas executaveis.
- `integrations/` para contratos com ferramentas externas.
- `data/` para amostras e esquemas seguros.
- `content/` para producao e templates.
- `experiments/` para prototipos.

## Consequencias

O repositorio fica pronto para crescer sem misturar prototipos, operacao e
documentacao. As pastas podem ganhar ferramentas especificas quando houver uso
real suficiente para justificar.

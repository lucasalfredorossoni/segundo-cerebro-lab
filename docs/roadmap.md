# Roadmap

## Agora

- Definir a primeira automacao real do laboratorio.
- Escolher quais fontes entram no primeiro ciclo: ClickUp, Drive, GitHub, Canva
  ou arquivos locais.
- Criar um inventario minimo dos dados que podem ser versionados.
- Padronizar nomes de pastas, arquivos e entregaveis.

## Proximo ciclo

- Implementar um script pequeno de ponta a ponta em `automations/`.
- Criar um exemplo seguro em `data/samples/`.
- Documentar o contrato da primeira integracao em `integrations/`.
- Criar um template de briefing ou pauta em `content/templates/`.

## Depois

- Adicionar testes para automacoes criticas.
- Criar rotina de execucao local com comandos padronizados.
- Mapear permissoes e segredos necessarios para cada integracao.
- Criar dashboards ou relatorios gerados automaticamente.

## Ideias em avaliacao

- Sincronizar tarefas relevantes do ClickUp para um resumo semanal.
- Transformar notas do Drive em backlog de conteudo.
- Gerar briefings de posts a partir de estudos e dados internos.
- Consolidar status de repositorios GitHub em um painel operacional.
- Criar pacotes Canva a partir de pautas aprovadas.

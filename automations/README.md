# Automations

Scripts, jobs e fluxos que executam trabalho repetivel.

Cada automacao deve ter:

- uma pasta propria;
- um README com objetivo, entradas, saidas e modo de execucao;
- configuracao via variaveis de ambiente;
- nenhum segredo versionado.

## Estrutura sugerida

```text
automations/
  nome-da-automacao/
    README.md
    src/
    tests/
```

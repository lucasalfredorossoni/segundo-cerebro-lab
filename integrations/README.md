# Integrations

Contratos, notas e mapeamentos para ferramentas externas.

Use uma pasta por ferramenta ou servico. Exemplos:

- `clickup/`
- `canva/`
- `drive/`
- `github/`

Cada integracao deve explicar:

- finalidade;
- autenticacao necessaria;
- dados lidos;
- dados escritos;
- limites, riscos e frequencia de uso.

# Data

Dados seguros para desenvolvimento, documentacao e testes.

Nao coloque aqui arquivos sensiveis, privados ou grandes. Para dados reais, use
fontes externas apropriadas e documente apenas o contrato em `data/schemas/`.

## Subpastas

- `samples/`: amostras pequenas e anonimizadas.
- `schemas/`: formatos esperados, dicionarios e contratos.
- `processed/`: saidas derivadas que podem ser regeneradas.

# Triagem Local

Esta pasta e reservada para saidas geradas pelo comando `cerebro triagem`.

Os registros gerados ficam fora do Git por padrao:

- `drafts/`: rascunhos de triagem.
- `official/`: registros oficiais locais.

Isso evita versionar dado sensivel por acidente. Quando um formato estiver
maduro e seguro, versionar apenas exemplos ficticios em `data/samples/`.
